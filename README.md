# Ação - Sistema Contábil — programa pronto

Este repositório guarda **somente o programa pronto** do *Ação - Sistema Contábil*, usado para
instalar e atualizar os computadores do escritório.
**Não contém código-fonte nem dados** — os dados ficam apenas na pasta principal do escritório.

## Instalar no Windows (uma vez em cada computador)

1. Baixe o instalador: **[Instalar-Acao-Sistema-Contabil.exe](https://github.com/rafaelvannis/acao-sistema-contabil-programa/releases/latest/download/Instalar-Acao-Sistema-Contabil.exe)**
2. Dê dois cliques. Se aparecer "O Windows protegeu o computador": *Mais informações* → *Executar assim mesmo*.
3. Pronto: o atalho **Ação - Sistema Contábil** fica na Área de Trabalho. Não precisa de administrador.

Mac: em breve.

## Atualizações

Depois de instalado, o programa procura versão nova sozinho ao abrir e pergunta se pode atualizar.
Só o programa é baixado; nenhum dado sai do computador. (O arquivo `.zip` das versões é usado
apenas pela atualização automática — não precisa baixá-lo.)
