# Ação - Sistema Contábil — programa pronto

Este repositório guarda **somente o programa pronto** (executáveis) do *Ação - Sistema Contábil*,
usado para instalar e atualizar os computadores do escritório.
**Não contém código-fonte nem dados** — os dados ficam apenas na pasta principal do escritório.

## Baixar a última versão

- **Windows:** [Acao-Sistema-Contabil-Windows.zip](https://github.com/rafaelvannis/acao-sistema-contabil-programa/releases/latest/download/Acao-Sistema-Contabil-Windows.zip)
- **Mac:** em breve.

## Instalar (uma vez em cada computador)

**Windows:** extraia o .zip (botão direito → *Extrair tudo*) e abra `Acao - Sistema Contabil.exe`.
Se aparecer "O Windows protegeu o computador": *Mais informações* → *Executar assim mesmo*.
O programa oferece **Instalar neste computador** (cria o atalho na Área de Trabalho).


## Atualizações

Depois de instalado, o programa procura versão nova sozinho ao abrir e pergunta se pode atualizar.
Só o programa é baixado; nenhum dado sai do computador.
